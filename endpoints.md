## Users API

- GET /users
- GET /users/:id
- POST /users
- PUT /users/:id
- DELETE /users/:id

## Game API

- GET /game - Get game info
- GET /game/:id - Get specific game
- POST /game - Create new game
- PUT /game/:id - Update game
- DELETE /game/:id - Delete game
- GET /constants - Fetch game constants (physics, speeds, etc.)
- WS /pong - WebSocket endpoint for multiplayer pong
